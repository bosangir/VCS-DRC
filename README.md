# VCS-DRC

Material from the UNIKIN independent vaccination coverage surveys in the Democratic Republic of the Congo.

- **Website: <https://bosangir.github.io/VCS-DRC/>** (French and English). Everything for the data quality training on one page: the six key messages, the process poster, the segment protocol demonstration, live demonstrations of the CAPI card-date checks and active interview duration, messages by role, disposition codes, alerts, the enumerator self-check and all downloads. Source: [`docs/`](docs/).
- [`field-quality-assurance/`](field-quality-assurance/): the training material itself. It includes a guide by role (French and English), a process poster, an interactive demonstration of the compact segment protocol, and the scripts that build the guide, poster and website.
